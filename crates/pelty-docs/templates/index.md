# PeltyCMS developer docs

These pages are generated by `cargo xtask docs` (the `pelty-docs` crate) from the code itself: the router, the OpenAPI schema, the event registry, the WASM runtime types, the WIT world, the UI schema, the config loader, the migrations directory and the example addon in `extensions/examples/addon-guide`. If a page and the code disagree, the generator is wrong. Please report it as a bug.
